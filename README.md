# 허니듀

부부가 링크 하나로 함께 여는 출산 서포트 페이지.
한 사람은 이번 주 할 일을 읽고, 다른 한 사람은 요청을 남긴다.
설치·가입·로그인 없음.

## 구조

- `index.html` — 페이지 전체. 의존성은 웹폰트와 Firebase SDK 둘뿐이다
- `database.rules.json` — Realtime Database 규칙

## 데이터가 어디 있나

**이 저장소에는 어떤 개인 정보도 없다.** 날짜도 내용도 소스에 넣지 않는다.

- 방 열쇠는 URL 해시(`#`) 뒤에만 있다. 해시는 서버로 전송되지 않는다
- 날짜는 첫 실행 때 설정 화면에서 받아 Realtime Database 에만 저장된다
- 규칙은 열쇠 길이 24자 이상인 방만 읽고 쓰게 한다

## 보안 모델 — 정직하게

**링크를 아는 사람은 읽고 쓸 수 있다** (capability URL).
진짜 인증을 붙이면 상대가 로그인을 해야 하고, 그러면 "링크 눌러서 바로 열림"이라는
이 페이지의 유일한 요구가 깨진다. 그 교환을 알고 선택한 것이다.

열쇠가 새면 방을 새로 만들면 된다. 링크를 공개된 곳에 올리지 말 것.

## 설정

1. Firebase 프로젝트 생성 → Realtime Database 만들기
2. `database.rules.json` 내용을 규칙에 붙여넣기
3. 웹 앱 등록 후 설정값을 `index.html` 상단 `FB` 에 채우기
4. GitHub Pages 로 배포
